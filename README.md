# Axiom Reach

High-school math open-world game (Three.js). Algebra I → II, Geometry, Trig.

**Play online (GitHub Pages):** https://robglnn.github.io/aabmath/  
**Gauntlet workbench:** https://robglnn.github.io/aabmath/workbench.html

## Dev

```bash
npm install
npm run dev
```

- Game: http://localhost:5173/
- Workbench: http://localhost:5173/workbench.html

See `docs/handoff.md` for locked scope and Gauntlet rules. Pages deploy on push to `main` via `.github/workflows/deploy-pages.yml`.
