# Product Context

## Problems
- Drill apps feel like worksheets; AAA games rarely teach real math mastery.
- State standards fragmentation pushes teams toward duplicated content.

## Experience goals
- Feels like an approachable open-world action game within seconds (touch or PC).
- Lessons feel in-world (chalkboard, dig sites, hub), not a mode switch to “school app.”
- Progress Report makes TEKS + Common Core (and later other jurisdictions) legible.
- Students cannot complete a skill/lesson below 80% mastery.

## How it should work
Roam → dig/reveal or enter lesson → explicit teach → practice → 80% gate → unlock → review returns prior skills.
