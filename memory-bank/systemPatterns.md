# System Patterns

## Architecture (v1)
- **Vite + TypeScript + Three.js** game client
- **DOM HUD** over WebGL canvas (pixel/retro styling from concept)
- **Content JSON** consumed by lesson runner + adaptive layer
- **Pedagogy services:** knowledge graph, mastery (≥80%), IRT attempts, spaced review queue, standards index

## Gauntlet
- Lead splits work; Builder + fresh Critic per piece; loop on largest gap
- Models: `cursor-grok-4.5-high`, `composer-2.5`; Opus 5 sparingly; no Kimi; no fast variants
- Live `workbench.html` for progress

## Content pipeline
Architect → KP spec → Lesson design → Items → Pedagogy critic → Localize ES/PL → Integrate
