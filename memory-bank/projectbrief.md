# Project Brief — Axiom Reach

## What
Web third-person educational math game (Three.js) for high-school Algebra I/II, Geometry, Trig. Landscape iPhone + PC.

## Why
Make mastery unavoidable and feel powerful: optimistic light-dystopian open landscape; progress gated on real skill (≥80%).

## This run
Algebra I Lessons 1–3 (EN/ES/PL), playable vertical slice, reusable content/pedagogy pipeline for later courses.

## Constraints
- Three.js only (no Phaser)
- PS1/PS2 AAA visual bar; Fortnite = approachability only
- Single region, light lore
- v1 verbs: move, palm laser dig, lesson, hub
- Heavy pedagogy real for L1–L3 (graph, IRT, spaced review, standards tags)
- KaTeX for all math
